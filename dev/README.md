# 개발선 아카이브 (`dev/`)

이 디렉터리는 **프로덕션 이전**에 공개했던 펌웨어 폴더를 보관합니다.

## 왜 여기 있나

2026-08-06에 프로덕션 메인라인을 **v1.0.0**으로 리셋하면서,

- 과거에 루트에 있던 공개 `v1.x.x/` 폴더를
- 메이저만 **1 → 0**으로 바꾼 뒤
- 모두 `dev/v0.x.x/` 아래로 옮겼습니다.

| 과거(루트) | 현재(아카이브) |
|------------|----------------|
| `v1.3.3/` | `dev/v0.3.3/` |
| `v1.3.2/` | `dev/v0.3.2/` |
| `v1.2.12/` | `dev/v0.2.12/` |
| … | … |
| `v1.0.0/` (초기 공개) | `dev/v0.0.0/` |

루트 [`v1.0.0/`](../v1.0.0/) 은 **새 프로덕션**이며, `dev/v0.0.0/` 과는 다른 릴리스입니다.

## OTA·배포 시 주의

- 장치 **Check Latest / Install Latest** 는 `main` **루트**의 `vX.Y.Z/` 만 봅니다. **`dev/`는 스캔하지 않습니다.**
- 아카이브 manifest 서명/`manifest.sig`는 경로·버전 필드 수정으로 검증이 깨져 있을 수 있습니다.
- 바이너리 내부 버전 문자열은 원래 1.x 빌드값을 유지할 수 있습니다(재빌드 없음).
